# Bytemancer

A dark theme for VS Code, ported from the [Bytemancer Emacs theme](https://github.com/mcminnra/dotfiles).

## Installation

1. Clone or copy this directory
2. Open VS Code and run **Extensions: Install from VSIX...** or use **Developer: Install Extension from Location...**
3. Select **Bytemancer** from **Preferences: Color Theme**

## Color Palette

| Color  | Hex       | Usage                    |
|--------|-----------|--------------------------|
| Red    | `#EE6D85` | Keywords, operators      |
| Orange | `#F6955B` | Constants, decorators    |
| Yellow | `#D7A65F` | Strings, search matches  |
| Green  | `#95C561` | Functions                |
| Blue   | `#7199EE` | Types, classes           |
| Cyan   | `#38A89D` | Links, namespaces, regex |
| Purple | `#A485DD` | Numbers, built-ins       |
